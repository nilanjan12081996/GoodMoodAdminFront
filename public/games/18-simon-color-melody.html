Color Memory
Level: 0
🎮 Color Sequence Memory — How to Play
🎯 Objective

Watch and repeat glowing musical color melodies in correct sequence.

🕹️ How to Play
  • Tap 'Start Game' and observe the color pads light up in sequence.
  • Tap the pads in the exact same order to pass the round.
  • Each successful round adds one more color note to the memory melody.
🌿 Wellness Benefit

Trains active working memory, pattern recognition, and calm auditory-visual recall.
